# Project instructions

Before changing frontend UI, read [Website UI design rules](docs/ui-design-rules.md). These record the user's approved visual conventions and apply to existing and new pages. Preserve the purple focus outline, neutral persistent selection, lighter hover, white selected top module tabs, shared heading typography, and compact aligned spacing. Later explicit user requests take precedence.

Inventory enhancements are reviewed one at a time. Complete the current enhancement and wait for the user's review before moving to the next.

Overflowing panels must scroll their content or options while keeping headers and search controls visible. Follow the Scrolling and fixed controls section in the UI rules.
