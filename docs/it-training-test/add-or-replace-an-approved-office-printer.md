# Add or replace an approved office printer

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Use when a computer needs an existing authorized printer.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Obtain the approved printer identity, location, connection method and print queue from IT.
2. Check device/network access and use the approved Windows deployment process or company software portal.
3. Install the supported manufacturer/IT-approved driver for the correct OS and architecture.
4. Choose default printer behavior with the employee and verify duplex/color settings match their approved needs.
5. Print a non-sensitive test page, confirm the physical device and ensure confidential-print controls are configured when required.
6. Document the queue and driver version; remove obsolete queues only after approval.

## Verification and ticket closure
Confirm the employee can choose and use the correct printer after sign-in/restart. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate missing driver support, admin requirements, access restrictions or confidential-print configuration uncertainty.
