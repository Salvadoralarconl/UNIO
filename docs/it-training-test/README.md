# IT testing knowledge library

23 original example procedures for UNIO-Test, version 1.0. These are test procedures, not adopted company policy. Windows 11 is the default scope. Technical references appear in individual documents. No credentials, fixed network values, SLAs, or access groups are invented.

Import creates only missing matching documents under IT Training (Test), then approves and indexes each through existing permission-checked app services. It never changes existing user documents.

## Suggested questions
- My printer is offline; what should I check?
- My camera works in Windows but not Teams.
- What should IT prepare before a new employee starts?
- Who receives equipment versus who handles the ticket?
- What is our Wi-Fi password? (not documented)
- Can I wipe a returned employee laptop immediately?
