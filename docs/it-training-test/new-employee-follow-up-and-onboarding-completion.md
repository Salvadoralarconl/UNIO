# New employee follow-up and onboarding completion

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Example follow-up checklist after initial handover.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Review the onboarding request and each linked task for actual completion.
2. Ask the employee and manager whether equipment, applications and communication tools meet approved needs.
3. Check unfinished access/license items and confirm each has a technician and next action.
4. Confirm Inventory recipient, department, location and accessories match the handover.
5. Document orientation and known limitations. Do not claim an account is fully ready when mandatory setup is still pending.
6. Close the request only after verification; retain related evidence according to company retention requirements, which are not specified in this test guide.

## Verification and ticket closure
Confirm no mandatory tasks remain open and the employee/manager acknowledge completion. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate persistent access failures, inconsistent asset custody, unclear ownership or unmet accessibility needs.
