# Dock monitors keyboard and USB troubleshooting

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Use when peripherals work intermittently or are not detected through a dock.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. List the affected peripheral, dock model, computer model and whether it worked previously.
2. Check dock power, approved cable and secure connections. Test the peripheral directly on the computer.
3. Test one known-good cable or port at a time. Confirm that a charging-only cable is not being used for data/display.
4. For monitors, verify the correct input and display arrangement; compare an approved direct video connection.
5. Ask the employee to save work before reconnecting the dock or restarting. Use only approved firmware/driver updates.
6. Document whether the issue follows the peripheral, cable, dock or computer.

## Verification and ticket closure
Confirm each required display and input device works after reconnecting. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate overheating, damaged ports, recurring disconnects or suspected incompatibility.
