# Webcam not detected or black image

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Use when the camera is missing, blank or unavailable in all apps.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Check the physical privacy shutter, camera-disable key and external camera cable.
2. Test an external webcam directly on a known-good USB port rather than a dock.
3. Close other applications using the camera and test the Windows Camera app.
4. Check Windows camera permissions for the intended application, including desktop-app access where applicable; respect organization-managed restrictions.
5. If the camera is absent from Device Manager or has an error, record it and obtain an approved driver/update from IT.
6. Restart with consent and repeat the camera test. Do not disable endpoint security to enable the camera.

## Verification and ticket closure
Confirm preview in Windows and then in the employee meeting application. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate managed permission blocks, physical damage, persistent detection failure or hardware error codes.
