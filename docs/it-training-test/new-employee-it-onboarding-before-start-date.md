# New employee IT onboarding - before start date

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Example checklist for HR, manager and IT preparing a new employee.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Obtain an approved manager/HR request with start date, employee name, department, work location and role. Do not assume access from a job title alone.
2. Create the Employee directory entry for equipment allocation. Employee entries do not themselves grant a login.
3. Identify approved equipment kit and accessories. Create a request linked to the equipment recipient and assign signed-in technicians to its ticket.
4. Obtain approval for each application, group and license. IT must confirm actual company access rules; this example defines none.
5. Prepare device, asset record, updates, endpoint management and required applications using the approved build process.
6. Schedule handover and ensure the employee receives access instructions through an approved channel without shared passwords.

## Verification and ticket closure
Confirm account/equipment readiness, technician ownership and a scheduled start-day handover. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate missing manager approval, insufficient stock/licenses, unclear role access or changes to the start date.
