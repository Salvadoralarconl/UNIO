# Computer will not power on or has a blank screen

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Distinguish no power, no display and a Windows boot failure.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Check for heat, smoke, liquid damage or a swollen battery. If present, stop and disconnect power when safe.
2. Confirm outlet, power cable and correct manufacturer-approved charger. Observe power lights and fan activity.
3. For an external monitor, confirm monitor power, input and cable; test a known-good display/cable.
4. Remove nonessential peripherals and test direct power rather than a dock. Avoid opening the device.
5. If Windows is running but the display is blank, check display selection and record the behavior; if startup fails, capture the exact error and contact IT.
6. Do not reset, format, alter firmware settings or clear encryption without an approved recovery plan.

## Verification and ticket closure
Confirm normal boot, sign-in and stable display on the intended screen. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate persistent no power, hardware error codes, a missing recovery key, recurring boot failure or suspected data loss.

Microsoft support reference (consult for device-specific details): https://support.microsoft.com/en-us/windows/hardware/display-graphics/troubleshooting-blank-screens-in-windows
