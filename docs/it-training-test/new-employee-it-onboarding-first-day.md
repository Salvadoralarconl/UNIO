# New employee IT onboarding - first day

TEST KNOWLEDGE BASE - Example IT procedure, version 1.0, reviewed 2026-10-10. This is training/test documentation, not an adopted UNIO policy. Applies to Windows 11 unless stated otherwise. Product models, approvals, support contacts, access groups, SLAs and configuration values must be confirmed locally. Never invent them.

## Purpose and symptoms
Example first-day checklist for technician and equipment recipient.

## Before you start
Record the ticket, employee, asset tag, exact symptom/error, when it began, recent changes, and whether other users are affected. Obtain consent before interrupting work. Protect private information; never collect passwords, MFA codes, recovery keys or unrestricted screenshots.

## Procedure
1. Confirm identity and hand over recorded equipment/accessories; inspect condition together.
2. Have the employee sign in themselves, set credentials through the approved flow and enroll MFA.
3. Confirm approved email, calendar, collaboration and business application access without granting unrelated permissions.
4. Test Wi-Fi/VPN where required, a printer, webcam, microphone and display setup.
5. Explain how to request support, report suspicious messages, lock the screen and use the approved file/backup location.
6. Update equipment assignments and record employee acknowledgement. Create follow-up tickets for incomplete items instead of marking them complete.

## Verification and ticket closure
Have the employee perform representative work and acknowledge handover. Record the steps attempted, observed result, technician and time in the ticket. Close only after the employee confirms the original task works.

## Stop and escalate
Escalate failed identity verification, missing access approvals, security enrollment problems or equipment defects.
