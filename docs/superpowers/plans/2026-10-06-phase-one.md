# Clary Phase One Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a small running Clary workspace that retrieves approved sample passages, calls OpenAI, and displays validated citations.

**Architecture:** React calls a local ASP.NET Core API. The API indexes sample Markdown in PostgreSQL/pgvector, retrieves approved passages, and validates structured responses from a replaceable provider. Deterministic tests are separate from live evaluations.

**Tech Stack:** .NET 10 SDK, ASP.NET Core, Npgsql, pgvector, xUnit, React, TypeScript, Vite, Docker Compose.

**Spec:** ../specs/2026-10-06-sourcedesk-design.md

## Review Focus

- Approval revoked during generation: suppress advice and prevent passage access (task 4).
- Embedding dimensions/model changed: reject old indexes and explain reindexing (task 2).
- Empty or malformed provider response: show a safe failure without rendering partial advice (task 3).
- Database restart or partial indexing: preserve metadata and never publish incomplete indexes (task 2).
- Source strings containing HTML or instructions: render as text and never grant capabilities (tasks 4 and 5).

## Shared Contracts and File Map

Paths below are relative to the project root.

- `backend/Clary.Api/Program.cs`: configuration, dependency injection, endpoints.
- `backend/Clary.Api/Contracts.cs`: records `EmbeddingProfile(Provider, Model, Dimensions, ChunkingVersion)`, `Passage(Id, RevisionId, Text, Location)`, `Citation(PassageId, Quote)`, `AdviceStep(Text, Citations)`, and `Answer(Status, Questions, Steps, Citations, Origin, Error)`.
- `backend/Clary.Api/Knowledge/`: chunking, indexing, sample loading, database repository.
- `backend/Clary.Api/Ai/`: separate provider interfaces, OpenAI adapters, deterministic test provider, orchestration and validation.
- `backend/Clary.Tests/`: unit and PostgreSQL integration tests.
- `database/001-initial.sql`: schema and vector extension.
- `samples/`: fictional VPN, printer, draft, conflict, and injection fixtures with metadata manifest.
- `frontend/src/`: typed API client, Clary workspace, source panel, and styles.
- `compose.yaml`, `.env.example`, `.gitignore`, `scripts/Start-Clary.ps1`, `README.md`: local operation.

Interfaces use CancellationToken on all network/database operations:

`IEmbeddingProvider.EmbedAsync(IReadOnlyList<string> texts, CancellationToken ct) -> Task<IReadOnlyList<float[]>>` plus `Profile`.

`IAnswerProvider.GenerateAsync(string question, IReadOnlyList<Passage> passages, CancellationToken ct) -> Task<Answer>`.

`IKnowledgeRepository.SearchAsync(float[] query, EmbeddingProfile profile, int limit, CancellationToken ct) -> Task<IReadOnlyList<Passage>>` and `GetApprovedPassageAsync(Guid id, CancellationToken ct) -> Task<Passage?>`.

`TroubleshootingService.AskAsync(string question, CancellationToken ct) -> Task<Answer>`.
