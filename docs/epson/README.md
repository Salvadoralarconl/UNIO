# Epson TM printer knowledge base

Added 2026-10-06 for TM-T88IV, TM-T88V, TM-T20II, TM-T20III, and original TM-m30. The five `samples/epson-*.md` documents are project-authored, model-specific paraphrases with source URLs and section references. They are approved for this personal app, not endorsed by Epson or approved as workplace policy. Each advice paragraph names its applicable model.

Run `scripts/Download-EpsonManuals.ps1` to obtain the original Epson manuals and TM-m30 troubleshooting HTML pages in `docs/epson/originals`. Original files are ignored by Git; the download script preserves reproducible source locations. Downloaded HTML is for reference, not executable app content.

The running app searches the curated Markdown notes, not the full original PDFs. Full PDF ingestion remains a later phase. Citation quotes are exact excerpts of the curated notes; they are not represented as verbatim quotations from Epson. URLs in the passage identify the original source, which can be opened separately. Coverage is intentionally limited: no invented network reset, firmware-update, interface-specific, or driver-change procedures.

The user-supplied `Epson Receipt Printer Troubleshooting.docx` has also been imported as **one complete document**, preserving all 335 paragraph texts and their order. The original file is retained in `originals`, with its SHA-256 recorded in the extracted Markdown. It is identified as user-provided USB/APD documentation rather than an official Epson publication. Internal search chunks are passages of that single document, not separate Knowledge Base entries. USB/APD/Windows questions can retrieve this shared procedure alongside the named model's notes; hardware-only model questions do not automatically include it. The Word guide's technical claims are preserved, not independently certified by this import.

To publish new notes, use `scripts/Start-Clary.ps1 -Compose -Provider Ollama`, then POST `/api/samples/index` or click the sample indexing button. Embeddings use the existing EmbeddingGemma profile. Refresh Knowledge Base to inspect approval and indexing status.

Try model-specific power, paper, jam, and LED questions. `EpsonEvidence` restricts retrieved documents by the curated title's exact model before generation. Missing, unsupported, or multiple Epson models request clarification; filtered-out evidence causes abstention. This title convention is specific to the curated collection; general uploads will need explicit model metadata. Complete procedure paragraphs are required for Epson steps to reject overlapping chunk fragments. These controls do not prove that every relevant passage was retrieved or that a selected procedure applies to the reported symptom.

Run `scripts/Evaluate-Epson.ps1` to check five live model-specific questions, exact quotations, model provenance, and unspecified-model clarification. Initial live evaluation exposed a cross-model self-test answer; model scoping and incomplete-paragraph rejection were added before the final evaluation. Direct downloads from `download4.epson.biz` were blocked by Epson's server in this environment; three originals from `files.support.epson.com` downloaded successfully. Links remain available for blocked documents.
